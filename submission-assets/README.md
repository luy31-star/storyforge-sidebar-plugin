### 详情介绍（3000 字以内）

```text
StoryForge AI 视频生成是一款面向飞书多维表格的侧边栏插件，帮助内容团队在表格中完成批量视频创作。

配置提示词字段、参考附件字段和输出视频字段后，插件会读取当前记录，按所选模型的真实能力展示可填写参数，并调用 StoryForge 生成视频。任务完成后，视频自动下载并回写到指定附件字段。

当前开放 4 个精选模型：
• 瞬造 Seedance 2.5 720p：8 积分/次
• 瞬造 Seedance 2.5 480p：6 积分/次
• 渠道一 lec-seedance-2-0-933-stable：4.3 积分/次
• CNTCN MiniMax H3：2.5 积分/次

产品特点：
• 按行读取提示词，适合批量分镜、营销素材和视频内容生产
• 支持模型允许的图片、视频和音频参考
• 只要求用户填写当前任务和模型真正需要的信息
• 参数、时长、画幅和参考数量按模型约束动态展示
• 模型渠道与价格透明显示
• 自动轮询任务状态，完成后将视频写入多维表格附件字段
• 使用用户自己的 StoryForge API Key，任务、积分、计费和支付记录统一归属到该 Key
• 可通过邮箱创建或找回 API Key，同一邮箱只绑定一个 Key
• 支持通过 API Key 或绑定邮箱使用支付宝充值，充值本身无需验证码

使用前请确保提示词和参考素材合法合规，并对生成结果进行人工审核。需要依法标识的 AI 生成或合成内容，请按适用规则添加清晰标识。
```
