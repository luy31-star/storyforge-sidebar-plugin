# StoryForge AI 视频生成 - 飞书多维表格侧边栏插件

在飞书多维表格侧边栏中直接调用 StoryForge AI 生成视频，支持提示词 + 图片/视频/音频参考，生成完成后自动回写视频附件到表格。

## 功能特性

- 🎬 **一键生成**：选中一行记录，点击按钮即可生成视频
- 🎨 **StoryForge 风格界面**：图片化灵感预览、步骤化配置和窄侧边栏适配
- 🎯 **模型能力对齐**：仅开放已接入 StoryForge 的瞬造 Seedance 2.5、渠道一 933 Stable 与 CNTCN MiniMax H3
- 📝 **按需字段映射**：提示词和输出视频为必填，图片/视频/音频参考字段仅在当前模型支持或要求时显示
- ⚡ **实时进度**：侧边栏实时显示生成进度，支持多任务并行
- 🔄 **自动回写**：视频生成完成后自动下载并写入表格附件字段
- 📦 **批量生成**：支持一键批量生成所有记录
- 🔑 **本地存储配置**：API Key、字段映射、模型参数自动保存到浏览器
- ⏰ **无超时限制**：纯前端运行，视频生成 1 小时也没问题（轮询超时设为 1 小时）


## 安全审核说明

- 插件是纯前端侧边栏应用，不包含 StoryForge 服务端源码、数据库配置或渠道密钥。
- API Key 仅由用户在插件内填写并保存在当前浏览器的 `localStorage`；源码仓库不包含任何真实 Key。
- 网络请求仅发往用户配置的 StoryForge API 地址，默认是 `https://www.storyforge.asia`。
- 插件只通过飞书多维表格 JS SDK 读取当前表格的字段和记录，并在用户主动生成后回写视频附件。
- 生产构建可通过 `npm ci && npm run build` 复现，生成目录为 `dist/`。
- 更完整的安全边界和审核清单见 [`SECURITY.md`](./SECURITY.md)。

## 技术栈

- React 18 + TypeScript
- Vite 构建
- `@lark-base-open/js-sdk`（飞书多维表格前端 SDK）

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器（默认端口 5173）
npm run dev
```

启动后，在飞书多维表格中添加自定义插件，服务地址填：
```
http://localhost:5173
```

> 注意：SDK 需要在飞书多维表格环境中运行，直接在浏览器打开 http://localhost:5173 会提示初始化失败，这是正常的。

## 构建部署

```bash
# 构建生产版本
npm run build
```

构建产物在 `dist/` 目录，将其部署到任意静态文件服务器即可。

### 部署到 StoryForge 服务器

假设你要部署到 `https://www.storyforge.asia/sidebar-plugin/`：

1. 修改 `vite.config.ts`，添加 `base: '/sidebar-plugin/'`
2. 执行 `npm run build`
3. 将 `dist/` 目录内容上传到服务器对应路径

### 部署到 Vercel / Netlify / GitHub Pages

直接将项目连接到这些平台，构建命令 `npm run build`，输出目录 `dist`。

## 在飞书多维表格中添加插件

1. 打开任意多维表格
2. 点击右上角「插件」图标（拼图形状）
3. 点击底部「自定义插件」
4. 点击「+ 新增插件」
5. 填写插件名称（如「StoryForge 视频生成」）和服务地址（如 `https://www.storyforge.asia/sidebar-plugin/`）
6. 点击「确定」

添加后，插件会出现在自定义插件列表中，点击即可在侧边栏打开。

## 使用说明

### 第一次使用配置

1. 打开插件，展开「开始前准备」
2. 填写 **StoryForge API Key**（格式：`sk-fd-xxxxxxxx`，在 StoryForge API 门户通过邮箱验证码获取）
3. 在「字段映射」中选择：
   - **提示词字段**（必填）：选择包含视频生成提示词的文本字段
   - **输出视频字段**（必填）：选择用于存放生成视频的附件字段
   - **参考图片字段**：瞬造 Seedance 2.5 必填，其余模型按需选填
   - **参考视频/音频字段**：仅在当前模型支持时显示，可选
4. 在「选择模型」中从已开放的模型列表选择模型，插件会自动同步画幅、时长、清晰度和规格约束
5. **API 地址**默认隐藏在「高级设置」中，一般无需修改
6. 配置会自动保存到浏览器本地，下次打开无需重新配置

### 已开放模型

当前侧边栏仅开放以下 4 个 StoryForge 路由，不提供任意模型 ID 输入：

| 路由 ID | 渠道 | 展示名称 | 价格 |
|---|---|---|---:|
| `sz-sd25-r2-720p` | 瞬造 | Seedance 2.5 · 720p | 8 积分 / 次 |
| `sz-sd25-r2-480p` | 瞬造 | Seedance 2.5 · 480p | 6 积分 / 次 |
| `lec-seedance-2-0-933-stable` | 渠道一 | Seedance 2.0 · 933 Stable | 4.3 积分 / 次 |
| `MiniMaxH3` | CNTCN | MiniMax H3 · 2K | 2.5 积分 / 次 |

不同模型的画幅、时长、参考素材数量和规格会自动约束；生成前也会校验附件数量。

### 生成视频

1. 在表格中选中一行记录（确保提示词字段有内容）
2. 插件会显示当前选中行的提示词预览
3. 点击「生成选中行视频」按钮
4. 任务列表中会显示生成进度
5. 生成完成后，视频会自动写入输出字段
6. 可以点击「下载视频」直接下载

### 批量生成

点击「批量生成」按钮，会遍历当前数据表的所有记录，逐行生成视频。适合一次性处理大量数据。

### 失败重试

如果任务失败（网络问题、余额不足等），可以在任务卡片上点击「重试」按钮重新生成。

## 注意事项

1. **附件字段要求**：输出字段必须是「附件」类型，参考图片/视频/音频字段也必须是「附件」类型
2. **视频大小**：生成的视频通过前端下载再上传到飞书，大视频可能需要较长时间回写
3. **API Key 安全**：API Key 存储在浏览器 localStorage 中，不会上传到任何第三方服务器
4. **权限**：插件以当前登录用户的身份操作多维表格，需要用户对表格有编辑权限
5. **参考附件 URL**：飞书附件的临时 URL 会传递给 StoryForge 服务端下载，请确保 StoryForge 服务端能访问飞书域名

## 与字段捷径（FaaS 版）的对比

| 特性 | 侧边栏插件（本项目） | 字段捷径 FaaS 版 |
|---|---|---|
| 超时限制 | 无（纯前端，可设任意超时） | 15 分钟硬限制 |
| 交互体验 | 好（进度条、任务列表、批量操作） | 一般（单元格状态） |
| 触发方式 | 手动点击按钮 | 自动/手动更新字段 |
| 配置复杂度 | 低（前端配置，一次保存） | 中（需要打包上传、审核上架） |
| 部署方式 | 静态网页，填 URL 即用 | 打包 zip，提交审核 |
| 适合场景 | 长耗时任务、需要交互控制 | 轻量快速、15 分钟内完成 |
